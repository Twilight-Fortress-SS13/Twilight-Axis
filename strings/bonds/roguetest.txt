# не проверяется вовсе.

# realm    - имя державы, должно совпадать с realm_name из map_adjustment.
# default  - ставка для любой пары, которую не покрыл ни блок, ни исключение.
# bloc     - держава или орден. Фракция принадлежит только одному блоку.
# matrix X - плотный треугольник ВНУТРИ блока X, порядок из объявления блока.
# matrix blocs - блок к блоку, порядок из объявлений bloc выше.
# override - точечное исключение, бьёт и блок, и межблоковую ставку.
#
# Ячейка: warmth/weight. warmth -100..100, weight 0..100.
# Порядок применения: default -> matrix блока -> matrix blocs -> override.
