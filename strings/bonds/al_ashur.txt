#            иначе шаблон не будет выбран ни на одной карте.
# default  - ставка для любой пары, которую не покрыл ни блок, ни исключение.
# bloc     - держава или орден. Фракция может принадлежать только одному блоку.
# matrix X - плотный треугольник отношений ВНУТРИ блока X. Порядок строк и столбцов
#            берётся из объявления блока, поэтому отдельная ось не нужна.
# matrix blocs - отношения блока к блоку. Одно число на пару блоков, порядок из
#            объявлений bloc выше.
# override - точечное исключение, которое бьёт и блок, и межблоковую ставку.
#
# Ячейка везде одна и та же: warmth/weight. warmth от -100 до 100, weight от 0 до 100.
# Порядок применения: default -> matrix блока -> matrix blocs -> override.
