Боевой калькулятор

Каждый приём ближнего боя против каждого набора брони: сейчас (как в get_complex_damage / run_armor_check) → GURPS (бросок от Силы + урон оружия × damfactor / 10, броня как DR, множители раны). Значения GURPS — точное среднее по всем исходам кубиков, в старых единицах урона (рана × масштаб). Данные собраны из кода скриптом tools/combat_balance/build.py.

Пороги на единицу Телосложения

Порог = a × Телосложение + b. Увечье: 6·CON (60 при 10, 120 при 20). Отсечение: 11·CON − 20 (90 при 10, 200 при 20). Бросок увечья и отсечения: 3d6 против CON − ⌊рана / 5⌋.

Таблица DR по наборам брони

Используется, когда выбрано «таблица GURPS». Гибкая броня пропускает тупую травму, жёсткая и природная — нет. Значения в духе GURPS Basic Set / Low-Tech: стёганка 2*, кожа 2*, кольчуга 4/2*, бригандина 4, латы 6.
